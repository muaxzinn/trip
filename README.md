# Bangkok Trip Planner 2026 — Detailed Travel Comparison & Route Optimizer

เว็บไซต์สำหรับวางแผนท่องเที่ยวกรุงเทพฯ แบบละเอียด พร้อมระบบคำนวณงบประมาณ เปรียบเทียบโรงแรม 3 แห่ง จัดลำดับเส้นทางเที่ยวแบบต่อเนื่อง ค้นหาสถานที่ใกล้เคียง และแสดงแผนที่แบบโต้ตอบ (Interactive Map)

พัฒนาด้วย **HTML5, CSS3, Vanilla JavaScript, และ Leaflet Maps** โดยไม่พึ่งพา Framework หรือ Backend ขนาดใหญ่ สามารถเปิดใช้งานได้ทันทีบน Static Hosting และ **GitHub Pages**

## 🎯 คุณสมบัติเด่นของระบบ (Core Features)

1. **โครงสร้างแบบ 5 หน้าต่าง/วิว (5 Dedicated View Windows)**
   - แยกหมวดหมู่การใช้งานอย่างชัดเจน ไม่ต้องเลื่อนจอดยาวจนหาไม่เจอ:
     - 🏨 **หน้าต่าง 1: โรงแรม & ภาพรวม**: สรุปข้อมูลทริป สถิติหลัก และการ์ดเปรียบเทียบโรงแรม 3 แห่ง
     - 🗓️ **หน้าต่าง 2: แผนเที่ยวรายวัน**: ไทม์ไลน์เดินทางต่อเนื่อง พร้อมกล่องตั้งค่าวันสอบ ม.รามฯ และ 3 แผนทางเลือกของวันที่ 4
     - 🗺️ **หน้าต่าง 3: แผนที่ & ใกล้เคียง**: แผนที่ Leaflet พร้อมสารบบค้นหาร้านอาหาร ฮาลาล ร้านซักผ้า 24 ชม. และสถานี
     - 💰 **หน้าต่าง 4: คำนวณงบประมาณ**: ตารางคำนวณและเปรียบเทียบงบประมาณสุทธิ 3 โรงแรมแบบปรับแต่งได้
     - ⚖️ **หน้าต่าง 5: ประเมิน & อ้างอิง**: เมทริกซ์คะแนนถ่วงน้ำหนัก 10 ด้าน และดัชนีแหล่งข้อมูลอ้างอิง
2. **การออกแบบให้เหมาะกับมือถือ (Mobile-First Bottom Navigation)**
   - บนมือถือมี **Mobile Bottom Navigation Bar** สไตล์ Native App ด้านล่างหน้าจอ สลับ 5 หน้าต่างได้ด้วยนิ้วโป้งมือเดียว
   - บนเดสก์ท็อปและแท็บเล็ตมีแถบแท็บด้านบนสวยงาม พร้อมระบบ Hash Routing (#hotels, #planner, #map, #budget, #scoring)
3. **เปรียบเทียบโรงแรม 3 แห่งอย่างรอบด้าน (Hotel Comparison)**
   - **LEE Hotel Lat Phrao**: ใกล้ ม.รามคำแหง ที่สุด (~4.5 กม.) เดิน 250 ม. ถึง MRT สายสีเหลือง ลาดพร้าว 83 (YL05) ความเสี่ยงรถติดในวันสอบต่ำที่สุด
   - **Infinite Hotel @Ratchada**: เชื่อมต่อ MRT สายสีน้ำเงิน ตรงสู่พระนครและเยาวราช มีบริการรถตุ๊กตุ๊กรับกลับฟรีจาก MRT ห้วยขวาง
   - **Infinite Hotel @Kaset/Senanikom**: ราคาห้องพัก 4 คืนถูกที่สุด (3,120 บาท) ใกล้ BTS สายสีเขียว (สถานีเสนานิคม N12) ช่วยประหยัดเงินรวมทั้งทริปได้มากที่สุด
4. **ระบบจัดเส้นทางแบบต่อเนื่อง (Consecutive Route Optimizer)**
   - รับประกันว่าเมื่อเริ่มเดินทางท่องเที่ยวในวันนั้นแล้ว จะเดินทางต่อเนื่องจากสถานที่หนึ่งไปสู่อีกสถานที่หนึ่งจนจบวัน โดย**ไม่มีการเดินทางย้อนกลับโรงแรมระหว่างวัน**
   - **วันที่ 2 (วันสอบ ม.รามคำแหง)**: มีช่องปรับเวลาเริ่มสอบ, เวลาสิ้นสุด และเวลาสำรองเพื่อคำนวณเวลาออกจากโรงแรม
   - **วันที่ 4 (สวนหลวง ร.๙, สำเพ็ง, เยาวราช)**: มี 3 แผนทางเลือกให้เปรียบเทียบ (แผน A ประหยัดค่าเดินทาง, แผน B ลดเวลาเดินทาง, แผน C สมดุล)
5. **เครื่องคิดเลขงบประมาณแบบเรียลไทม์ (Budget Calculator)**
   - คำนวณแยกหมวดหมู่: ค่าห้องพัก, ค่าเดินทางสาธารณะ (MRT, BTS, เรือด่วนเจ้าพระยา, เรือข้ามฟาก, เรือแสนแสบ, รถเมล์), ค่า Grab สำรอง, ค่างบอาหาร (ค่าเริ่มต้น 180 บาท/วัน พร้อมตัวอย่างแบ่งมื้อ), และค่าซัก-อบผ้า (110 บาท/รอบ)
   - ปรับแต่งจำนวนคืน, จำนวนผู้เดินทาง, งบอาหาร, และราคาห้องได้อิสระ
   - ปุ่มคัดลอกสรุปงบประมาณลงคลิปบอร์ดในคลิกเดียว
6. **ระบบคะแนนถ่วงน้ำหนัก 10 คะแนน (10-Criteria Scoring Model)**
   - ประเมินคะแนนแยก 10 ด้านตามหลักฐานเชิงประจักษ์ พร้อมคำอธิบายเหตุผล
   - ผู้ใช้สามารถเลื่อนปรับเปอร์เซ็นต์น้ำหนักของแต่ละหัวข้อได้ตามความต้องการส่วนบุคคล
7. **แผนที่แบบโต้ตอบ (Interactive Leaflet Map)**
   - ใช้ OpenStreetMap ไม่มีค่าบริการและไม่ต้องใช้ API Key ส่วนตัว
   - แสดงหมุดตำแหน่งพร้อมป้ายสถานะพิกัด (ยืนยันแล้ว / ประมาณการ) และปุ่มกดเปิดนำทางใน Google Maps
   - วาดเส้นเชื่อมโยงลำดับสถานที่ประจำวันอย่างชัดเจน
8. **ค้นหาสถานที่และสิ่งอำนวยความสะดวกใกล้เคียง (Nearby Places Directory)**
   - กรองตามระยะทาง (<= 500 ม., <= 1 กม., <= 2 กม.)
   - กรองร้านอาหารประหยัด, ตัวเลือกฮาลาล, ร้านสะดวกซัก 24 ชม. (Otteri, Maru, Wash House, Wonder Wash, WashXpress), รถไฟฟ้า/ท่าเรือ, และร้านที่เปิด 24 ชม.
9. **ระบบบันทึกข้อมูล (LocalStorage & JSON Backup)**
   - บันทึกการตั้งค่าแผนและงบประมาณอัตโนมัติในเบราว์เซอร์
   - รองรับการ Export / Import ข้อมูล JSON และรองรับการพิมพ์ / บันทึกเป็น PDF

## 🚀 วิธีเปิดใช้งานในเครื่อง (How to Run Locally)

เนื่องจากเป็น Static Website คุณสามารถเปิดใช้งานได้หลายวิธี:

### วิธีที่ 1: ใช้ Python HTTP Server (แนะนำ)
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:
```bash
python3 -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`

### วิธีที่ 2: ใช้ Node.js Serve หรือ npx
```bash
npx --yes serve .
```

## 🌐 วิธีนำขึ้นโฮสต์บน GitHub Pages (Deployment)

1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น Git Repository ของคุณบน GitHub
2. ไปที่เมนู **Settings** ของ Repository บน GitHub
3. เลือกแท็บ **Pages** ในเมนูด้านซ้าย
4. ในส่วน **Build and deployment > Source** ให้เลือก `Deploy from a branch`
5. ในส่วน **Branch** เลือก `main` (หรือ `master`) และเลือกโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. ภายใน 1-2 นาที เว็บไซต์จะเปิดใช้งานผ่าน URL: `https://<username>.github.io/<repo-name>/`

## 🔍 ข้อมูลพิกัดและแหล่งอ้างอิงที่ตรวจสอบแล้ว (Data Verification)

- **โรงแรมทั้ง 3 แห่ง**: พิกัดได้รับการยืนยันและตรวจสอบตำแหน่งจริงริมถนนและซอยหลัก
- **ค่าเรือด่วนเจ้าพระยา**: ตรวจสอบอัตราปัจจุบันของเรือด่วนธงส้มอยู่ที่ 16 บาทตลอดสาย และเรือข้ามฟากท่าเตียน-วัดอรุณ 5 บาท
- **MRT / BTS**: ตรวจสอบตามตารางอัตราค่าโดยสารของ รฟม. (MRT สายสีน้ำเงินและสายสีเหลือง) และ BTS สายสีเขียว
- **ร้านสะดวกซัก**: ตรวจสอบตำแหน่งสาขาจริงของ Otteri (ลาดพร้าว 87 และ เสนานิคม 1), Maru Laundry (รัชดา), Wonder Wash (เสนานิคม), และ WashXpress (เสนานิคม 1)
